# Google Play Store Data Analysis

## Project Overview
This project analyses Google Play Store applications to understand app categories, ratings, installs, pricing, and user sentiment.

## Objectives
- Analyse app distribution across categories.
- Study app ratings and installation patterns.
- Compare free and paid applications.
- Estimate app revenue by category.
- Analyse user review sentiment.
- Create an interactive business dashboard.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

## Dataset
Google Play Store Apps and Google Play Store User Reviews datasets.

## Key Findings
The analysis examines app competition, pricing strategies, installation patterns, and customer feedback.

## Dashboard
An interactive HTML dashboard is included in this project.
